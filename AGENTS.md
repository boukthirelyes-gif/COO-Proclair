## Livraison Proclair demandée par le propriétaire

Pour les améliorations autorisées du CRM, intégrer les lots validés à main et
publier sur le projet Vercel existant dans le même cycle lorsque les accès sont
disponibles. Un push sur une branche de travail n’est pas une livraison utilisateur.
Vérifier le commit réellement déployé et le statut Ready avant d’annoncer une mise
en ligne. Si un accès ou une clé manque, terminer le travail indépendant et nommer
le blocage ; ne jamais annoncer une publication non vérifiée. Préserver les données,
les fonctionnalités et les restrictions existantes. Cette préférence explicite
prévaut sur les anciens rapports qui prescrivent de laisser tous les lots en test.
