# Proclair wordmark — présentation corrigée
Cette itération corrige le rendu précédent jugé trop rapide. Le logo officiel fourni par l'utilisateur est conservé pixel pour pixel (`public/proclair-wordmark.webp`), sans réécriture des lettres.

## Hiérarchie visuelle
- **Connexion** : carte centrée sur fond bleu nuit, logo original bleu sur surface ivoire unique, sous-titre discret, plus de navigation superflue.
- **Sidebar** : adaptation monochrome claire obtenue au rendu CSS (grayscale + invert + screen), sans rectangle blanc ni nouvelle image exportée. Logo une seule fois dans l'application connectée.
- **Header** : texte métier discret plutôt que deuxième logo redondant.
- **Dashboard** : signature métier « Vitres · Gouttières · Softwash » plutôt que carte de logo blanche additionnelle.
- **Favicon** : P blanc sur carré bleu avec trait eau pour cohérence.
- **Mobile** : tailles et espacement du logo adaptés aux petites largeurs.

Aucune API, configuration de production, donnée ou permission modifiée. Les styles de contrats/PDF demeurent inchangés grâce à `@media screen`.
